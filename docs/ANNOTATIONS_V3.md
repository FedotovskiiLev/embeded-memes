# Индивидуальные разборы мемов — версия 3.0

В коллекции 374 изображения. Для **каждого** есть отдельный подробный разбор, составленный по визуальному содержимому и возможному культурному контексту. Это **не** утверждение об истинных мыслях персонажа или о замысле автора рисунка.

## Редактируемые источники

- `data/source/memes.json`: исходные ID, файлы, права, реставрации и технические данные.
- `data/source/annotations.json`: 374 уникальных разбора по числовым ID (`"127"` для `HAMPTER_0127`). Включает `НАЗВАНИЕ`, `ВИДНО`, `РЕАКЦИЯ`, `ПОДТЕКСТ`, `МЕХАНИКА`, `КОНТЕКСТ`, `ПОДХОДИТ`, `НЕ ПУТАТЬ`, `ПОИСК`. Опциональные поля: `ТЕКСТ`, `ПЕРСОНАЖ`, `ИСТОЧНИКИ`.
- `data/source/reference_sources.json`: проверяемые ссылки и ограничения их использования. Ссылки подтверждают **только культурный контекст**, не права на изображение и не единственную «правильную» эмоцию.

## Семантика полей

`ВИДНО` — только буквально видимые признаки лица, позы, предметов и надписей. `РЕАКЦИЯ` — тонкие возможные эмоциональные смеси. `ПОДТЕКСТ` — **варианты воображаемой внутренней реплики**, а не обнаруженный текст на картинке. `МЕХАНИКА` — откуда возникает комизм, несоответствие или узнаваемость. `КОНТЕКСТ` — отсылка на произведение, интернет-мем или тип ситуации с оговорками об уверенности. `НЕ ПУТАТЬ` — важные **отрицательные** признаки; они намеренно не используются как положительные ключевые слова в поиске. `ПОИСК` — короткие проверяемые поисковые фразы на русском и английском. `ТЕКСТ` — надпись, которая действительно видна, если она есть.

В каталоге присутствуют те же сведения в `analysis` с англоязычными ключами, понятными агентам. `catalog/agent_map.jsonl` и `catalog/agent_map.md` генерируются автоматически; править их напрямую не нужно.

## Обновление

Редактируй `data/source/annotations.json` и при необходимости `reference_sources.json`, сохраняя ID. Затем выполни:

```bash
python scripts/build.py --vectors
python scripts/validate.py --quick
node --test tests/*.test.cjs
```

Сборка пересоздаёт `catalog/catalog.json`, `data/catalog.js`, офлайн LSA-векторы, `catalog/agent_map.jsonl`, Markdown-карту и SQLite-поиск. Источники не изменяют картинки и не пересчитывают их пиксели. Если добавляется новый мем, сначала добавь его ID и разбор; сборка проверяет покрытие 1:1 и не позволит незаметно выпустить мем без описания.

**Ограничение:** 96-мерный TF-IDF/LSA — не нейронная E5-модель. Режим E5 в браузере является дополнительным, а его веса не включены в репозиторий.
