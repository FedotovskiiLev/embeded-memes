# Проверка выпуска 2.0.0

## Выполнено

- Визуальный AI-assisted пересмотр карточек; буквальные признаки отделены от интерпретации реакции. Это не человеческое утверждение.
- Автоматическая проверка соответствия исходного и генерируемого каталога, ID, статусов, связей, путей, размеров файлов и SHA-256 мастеров/WebP.
- Декодирование/проверка всех трёх основных изображений каждой карточки через Pillow; исходные байты сохранены отдельно.
- Проверка SQLite integrity и числа записей.
- Проверка порядка 452 строк LSA, размерности 96, хэша каталога и единичной нормы векторов.
- Node regression tests: конкретные действия и реакции, старые alias, опечатка «блакнот», карантин, отсутствие ошибочного `fork` у блокнота, фильтры и несовместимый индекс.
- Chromium: отображение desktop/mobile, интерактивные запросы, карточка, Escape, избранное/подборка в пределах сессии, alias, карантин, мобильное меню. Снимки находятся в `qa/`.

## Не выполнено / ограничения

Политика браузера среды запрещала прямые переходы на `file://` и localhost. Для проверки интерфейса HTML/CSS/JS загружены в память Chromium, URL изображений заменены на data URI их локальных байтов. Это проверяет отрисовку и логику интерфейса, но **не реальное развёртывание**, загрузку относительных ресурсов через Pages, native downloads или сохранность localStorage после перезапуска браузера.

Веса E5 в среде подготовки не загрузились. Worker и Node-адаптер имеют синтаксические проверки и используют первичную документацию, но полный нейроinference не протестирован. Векторы E5 не включены. Сетевую часть и поддержку конкретного устройства нужно проверить после явного включения режима.

Проверки поиска — регрессии на важных сценариях, не полноценный независимый benchmark и не гарантия точного понимания любого перефразирования. LSA ограничена небольшой коллекцией. Возможны оставшиеся неточности аннотаций; особенно осторожно с `confidence: medium/low`.

## Воспроизвести

```bash
python scripts/validate.py
node --test tests/*.test.cjs
```

`qa/validation.json` и `qa/search-tests.txt` содержат результаты конкретной сборки. Браузерный отчёт — `qa/browser-report.json`. При пересборке обновляйте их, а не объявляйте старые проверки актуальными автоматически.
