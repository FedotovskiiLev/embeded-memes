## Повторить проверки

```bash
python scripts/build.py --vectors
python scripts/validate.py
node --test tests/*.test.cjs
```

Для публикации `.github/workflows/publish-verified.yml` экспортирует файлы в чистую папку без `.git`, проверяет контрольные суммы и запускает быстрый валидатор и тесты поиска.
