# Добавление и исправление мемов

## Внести одну картинку

Импортируйте статический PNG, JPEG или WebP. GIF/WebM/анимированный WebP в этой версии не обрабатываются: импортёр откажется, а не потеряет кадры молча.

```bash
python scripts/add_meme.py /path/to/image.png \
  --collection other-memes \
  --collection-name "Другие мемы" \
  --slug cat-reading-newspaper \
  --title "Кот читает газету" \
  --description "Серый нарисованный кот держит раскрытую газету двумя лапами и смотрит поверх её верхнего края." \
  --reaction "Спокойное наблюдение за чужой драмой." \
  --use-case "Читаю новости" \
  --use-case "Наблюдаю со стороны" \
  --tag газета --tag кот --tag newspaper --tag reading \
  --author "Укажите автора или оставьте неопределённым" \
  --source-url "https://example.org/actual-source"
```

URL в примере — заглушка: замените реальным источником, не сохраняйте её в каталоге. `--collection-name` требуется только при создании коллекции. По умолчанию ID будет `MEME_0001`, затем следующий свободный. Можно явно задать `--id CAT_0001`. Slug — короткая английская формулировка через дефисы, без эмоции, которую нельзя обосновать. Исходные байты сохраняются в `originals/imports/`.

По умолчанию статус **draft**: файл появляется в исходном каталоге, но не в обычной выдаче. После визуальной проверки измените статус на `reviewed` или используйте `--reviewed` при импорте уже проверенного материала. `--human-approved` — отдельное утверждение: не ставьте его за человека. Импортёр не запускает сборку самостоятельно.

```bash
python scripts/build.py --vectors
python scripts/validate.py
node --test tests/*.test.cjs
```

`--vectors` пересчитывает LSA после изменения описаний. При сборке без него несоответствующий каталогу браузерный индекс выключается, а не применяется к другим записям. Старые бинарные индексы могут оставаться в папке как артефакты предыдущей сборки — перед релизом нужен полный пересчёт.

## Как писать метаданные

**Что видно:** поза, направление взгляда, брови, веки, форма рта, руки, предметы и композиция. Не начинайте с общей эмоции. «Глаза полуопущены, рот тонкой горизонтальной линией, лапки опущены» полезнее, чем «уставший».

**Реакция:** аккуратная интерпретация, например «молчаливое неодобрение, скорее отстранённость, чем испуг». Не диагностируйте болезнь по выражению. Укажите неопределённость в `review_note`, если предмет неоднозначен.

**Ситуации:** короткие естественные реплики: «фиксирую замечания», «не впечатлило», «пытаюсь не расплакаться». Теги перечисляют реальные предметы, действия, выражения и английские синонимы; 10 бессмысленных общих слов хуже 5 точных.

Для связанных вариантов заполните `related_to` и `relation_type: visual_variant_or_edit`. Объясните, что поменялось: кроп, чёрные поля, добавленный бант, контур стикера. Не наследуйте детали, которые в варианте удалены. Не склеивайте разные выражения одним perceptual hash без проверки.

## Исправить существующую карточку

Сохраните ID. Измените `title`, `visual_description`, `reaction`, `use_cases`, `tags`, при необходимости `confidence`, предупреждения и статус. `slug` и `files` не переименовываются автоматически сборщиком. При переименовании переместите все версии файла и дополните `provenance/path_migration.json`.

Для замены низкокачественного исходника сохраняйте прежний файл и источники в `originals/`; обновите основные PNG/WebP, размеры и SHA-256. Старый кроп можно связать как `alternate`. Не называйте искусственное увеличение восстановленным оригиналом.

## Контроль перед коммитом

Сборка и валидация должны завершиться успешно. Откройте несколько изменённых карточек, проверьте поиск по конкретным предметам и негативные случаи. После реального развёртывания отдельно проверьте Pages URL, скачивание, сохранение избранного и мобильный экран. Изменились описания — пересчитайте E5 отдельно либо оставьте его выключенным. Не коммитьте кэш модели, окружения или `node_modules`.
