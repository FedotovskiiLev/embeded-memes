# Исходное оформление

Восстановлен дизайн из версии 2.0: тёмная боковая панель, светлый фон и прежние карточки. Коллекция называется «Хомячки». Второстепенные слоганы и декоративные подписи убраны.

| Элемент | Цвет |
| --- | --- |
| Основной фон | `#F3F2ED` |
| Текст и основные кнопки | `#24252A` |
| Боковая панель | `#222329` |
| Активная навигация и поиск | `#D6EE76` |
| Акцент, фокус и точка логотипа | `#7049C7` |
| Карточки и поле поиска | `#FFFFFF` |

В логотипе буква `e` тёмная, точка фиолетовая, фон лаймовый. При наведении карточка поднимается на 3 px и получает мягкую тень. Кнопки, пункты меню и коллекция меняют цвет. При предпочтении уменьшенного движения смещения отключены.

Длинные заголовки переносятся, карточки и поля не выходят за свои колонки. Фильтры переносятся по строкам. До 850 px навигация становится выдвижным меню; фон и Escape его закрывают, а основная область недоступна для нажатий, пока меню открыто.

Стили: `src/style.css`. Изображения показываются целиком через `object-fit: contain`.
