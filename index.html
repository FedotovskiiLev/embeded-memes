MULTILINGUAL E5 SMALL

Нейропоиск E5

Нейромодель запускается на твоём устройстве. При первом включении браузер скачает модель и токенизатор с Hugging Face — примерно 135 МБ, плюс библиотеку вычислений. Затем он построит векторы новых описаний. Запросы и изображения на сервер не отправляются.

Готовые векторы в этой версии — локальный TF‑IDF/LSA, не E5. Нейрорежим необязателен и требует первой загрузки из интернета. Полная загрузка E5 в среде сборки не была проверена.

Не включён. Обычный поиск уже работает без сети.
Векторы кэшируются в IndexedDB этого браузера. Для файлового открытия используй обычный поиск; E5 запускай через localhost или GitHub Pages. Подробности — SEARCH.md.
О БИБЛИОТЕКЕ

Embeded Memes
by Gliwy.dev

У каждой картинки теперь есть отдельные поля: что видно, как можно прочитать реакцию и для какой ситуации она подходит. Эмоция остаётся интерпретацией, а не доказанным фактом.

452 карточки доступны в обычном поиске. Ещё один почти пустой файл сохранён в карантине. Варианты кадрирования связаны, но не удалены. Низкое разрешение не маскируется апскейлом.

«Умный поиск» объединяет слова, словарь понятий и локальные LSA-векторы. Опциональный E5 — отдельная нейросеть. Наличие файла не означает разрешение на коммерческое использование.
